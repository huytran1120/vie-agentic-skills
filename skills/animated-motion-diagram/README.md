# Animated Motion Diagram (Agent Skill)

> Kỹ năng tạo sơ đồ kiến trúc hệ thống dạng **Bản vẽ kỹ thuật chuyển động (Animated Motion Diagram)** cho các AI Coding Assistant.

---

## ✨ Điểm nổi bật

- 🌊 **Dòng chảy chuyển động**: Các nét đứt trên mũi tên liên tục chuyển động theo chiều dữ liệu truyền đi.
- ⚡ **Hạt xung dữ liệu phát sáng**: Các hạt năng lượng dạng hạt tròn lướt mượt mà dọc theo các chu trình thực thi chính.
- 🎮 **Bảng điều khiển tương tác**: Tạm dừng, điều chỉnh tốc độ (0.5x, 1x, 2x), lọc theo luồng dữ liệu và chuyển chế độ Sáng/Tối.
- 🏷️ **Logo chuẩn chính thức**: Giữ nguyên logo vector gốc từ các kho chính thống (`svgl`, `devicon`).
- 📦 **Tự đóng gói 100%**: Chỉ 1 file HTML duy nhất, không phụ thuộc internet hay CDN ngoài, chạy offline hoàn hảo.

---

## 🚀 Cách sử dụng nhanh

```bash
# Chuyển đổi một sơ đồ kiến trúc có sẵn thành sơ đồ chuyển động:
python3 scripts/animate_diagram.py my_architecture.html my_animated_diagram.html
```
