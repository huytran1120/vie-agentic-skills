03

Bắt đầu với VAS

Đọc hướng dẫn →
  1. 01

    Tìm skill và chọn agent

    Duyệt catalog, xem nguồn và yêu cầu của runbook rồi chọn agent bạn muốn cài cho.

  2. 02

    Copy prompt cài skill

    Bấm “Copy Agent Prompt” ở skill, dán vào chat trong dự án đang mở. Agent tải đủ tệp mà không cần clone kho.

  3. 03

    Dùng trong agent

    Agent xác nhận đủ tệp, đọc SKILL.md và nêu yêu cầu còn thiếu. Nạp lại danh sách skill nếu ứng dụng yêu cầu rồi giao tác vụ của bạn.

Cách 2: quản lý bằng CLI — clone kho một lần

1. Tải kho và mở thư mục

git clone https://github.com/huytran1120/vie-agentic-skills.git && cd vie-agentic-skills && chmod +x vas vas.py && ./vas --help

2. Tìm và đọc một skill mẫu

./vas search code-review && ./vas show code-review

3. Cài skill vào đúng agent

Chọn “Dự án cụ thể” và nhập thư mục dự án của bạn, hoặc chọn “Toàn máy” để dùng trong nhiều dự án của cùng tài khoản. Chạy lệnh được tạo từ thư mục kho VAS đã clone.

4. Kiểm tra và bắt đầu dùng

Trong bảng cài đặt, mở “Sau khi cài: kiểm tra và dùng skill”. Chạy lệnh status, mở dự án trong agent rồi dán prompt mẫu và nêu tác vụ của bạn. Lệnh gỡ cũng được tạo đúng nơi đã chọn.

CLI dùng thư viện chuẩn Python 3, không cần NPX. Trên Windows, dùng Git Bash với Python 3; có thể thay ./vas bằng python3 vas.py. Mỗi runbook có thể yêu cầu công cụ riêng. Link cần giữ nguyên kho nguồn; copy là bản sao độc lập và không tự cập nhật theo kho VAS.
