Biên soạn bởi Vie Agentic Skill · Dựa trên runbook trong catalogPrepared by Vie Agentic Skill · Based on catalog runbooks

Khi kho kỹ năng dành cho AI coding agent phát triển lên hàng nghìn quy trình, câu hỏi quan trọng nhất không còn là "làm sao viết thêm một skill", mà là "làm sao chứng minh skill đó thực sự giúp agent giải quyết bài toán tốt hơn mà không gây xung đột hay rủi ro bảo mật".

As catalogs of AI coding agent skills expand into thousands of runbooks, the critical challenge shifts from authoring new skills to proving that a skill genuinely improves task outcomes without introducing collisions or security vulnerabilities.

1. Thách thức: Làm sao biết một Agent Skill có thực sự hiệu quả?1. The Challenge: Does a Skill Actually Improve Agent Outcomes?

Một runbook kỹ năng có thể được viết rất trau chuốt, nhưng điều đó không đảm bảo agent sẽ kích hoạt đúng lúc hoặc thực hiện thành công. Trong thực tế, các đội ngũ phát triển agent thường gặp phải ba vấn đề nan giải:

  • Ảo giác kích hoạt (Trigger Hallucination): Phần mô tả (description) trong tệp SKILL.md quá chung chung khiến agent gọi bừa bãi khi không cần thiết, hoặc quá hẹp khiến agent bỏ qua khi gặp bài toán liên quan.
  • Ô nhiễm ngữ cảnh và trùng lặp: Hai kỹ năng cùng hướng dẫn một chủ đề nhưng dùng chỉ dẫn trái ngược nhau (ví dụ một skill khuyên dùng tool A, skill khác cấm tool A), làm agent bị bối rối hoặc rơi vào vòng lặp vô tận.
  • Thụt lùi hiệu năng (Negative Skill Lift): Khi cài thêm skill, độ dài prompt tăng lên khiến agent mất tập trung vào nhiệm vụ chính, làm tỉ lệ hoàn thành nhiệm vụ thực tế giảm xuống so với khi không cài skill.

Để giải quyết bài toán này, các kỹ sư tại NVIDIA đã công bố bộ công cụ mã nguồn mở SkillEvaluator (nghiên cứu arXiv:2608.20614) cùng kỹ năng chính thức skillevaluator, biến việc đánh giá chất lượng kỹ năng thành một quy trình kỹ thuật định lượng và hoàn toàn tự động.

A skill runbook may be eloquently written, but that offers no guarantee that an agent will activate it reliably or execute tasks successfully. In production, agent engineering teams routinely face three failure modes:

  • Trigger Hallucination: A vague frontmatter description prompts spurious activations, while an overly narrow description leaves the skill dormant when genuinely needed.
  • Context Pollution and Overlap: Two skills provide contradictory guidance on the same workflow, confusing the agent and degrading instruction-following accuracy.
  • Negative Skill Lift: Inflated context windows diminish agent attention on primary instructions, reducing end-to-end task completion rates relative to baseline runs without the skill.

To establish rigorous benchmarks, NVIDIA engineers released the open-source SkillEvaluator framework (detailed in arXiv:2608.20614) and the official skillevaluator agent skill, transforming skill verification into an automated, quantitative engineering practice.

2. Kiến trúc 3 tầng của NVIDIA SkillEvaluator2. The 3-Tier Architecture of NVIDIA SkillEvaluator

Kỹ năng skillevaluator hướng dẫn agent lựa chọn và thực thi chính xác 3 tầng kiểm định theo mô hình lũy tiến:

Tầng kiểm định Mục tiêu & Phương pháp Yêu cầu tài nguyên Đầu ra chính
Tier 1: Tĩnh & Cú pháp Kiểm tra lược đồ, quét bảo mật SkillSpector, rà soát PII, chấm điểm cấu trúc và rubric ngữ nghĩa Chạy tức thì trên máy cục bộ; không bắt buộc API key (chỉ cần key khi bật rubric LLM) Điểm chất lượng (0–100), danh sách phát hiện bảo mật, báo cáo SARIF/JSON
Tier 2: Trùng lặp & Giao thoa Phân tích embedding ngữ nghĩa để tìm đoạn lặp trong nội bộ skill và đối chiếu chồng chéo với toàn bộ kho lưu trữ Mô hình embedding (như NVIDIA Build API hoặc provider tương thích) Tỉ lệ trùng lặp, ma trận tương đồng, gợi ý tinh gọn nội dung
Tier 3: Thực nghiệm A/B Chạy agent thật (OpenCode, Codex, Claude Code) giải quyết bài toán trong sandbox cô lập (Docker / Seatbelt) Docker daemon (hoặc sandbox máy chủ), provider LLM, bộ test cases evals/evals.json Chỉ số Skill Lift (%), tỉ lệ pass@k, phân tích trajectory đường đi của agent

The skillevaluator skill guides agents through a progressive 3-tier evaluation framework:

Tier Methodology Prerequisites Primary Artifacts
Tier 1: Static & Syntactic Schema validation, SkillSpector security checks, PII scanning, deterministic quality scoring, and rubric evaluation Local execution; keyless by default (provider key only required for LLM rubric) Quality score (0–100), security findings, SARIF/JSON reports
Tier 2: Deduplication Semantic embedding analysis to detect internal repetition and collection-wide overlaps Embedding provider (e.g. NVIDIA Build API or OpenAI compatible) Duplicate findings, similarity matrix, deduplication suggestions
Tier 3: Live Benchmarking Dual-arm A/B trials of coding agents (OpenCode, Codex, Claude Code) in isolated sandboxes (Docker / Seatbelt) Docker daemon or local sandbox, LLM credentials, evals/evals.json test suite Skill Lift (%), pass@k success metrics, trajectory execution logs

3. Tier 1: Kiểm tra tĩnh, quét bảo mật không cần API Key3. Tier 1: Static Quality, Security, and Keyless Scanning

Một điểm xuất sắc của SkillEvaluator là bạn có thể thực hiện kiểm định Tier 1 hoàn toàn không cần tài khoản hay khóa API trả phí. Lệnh quality-check phân tích cấu trúc tài liệu của SKILL.md theo các tiêu chí khách quan:

  • Có đầy đủ các phần bắt buộc như ## Prerequisites, ## Limitations, ## Troubleshooting không?
  • Phần description có nêu rõ tác vụ cụ thể hay chỉ nhồi nhét từ khóa quảng cáo?
  • Các đoạn code mẫu và cờ lệnh có được giải thích rõ ràng không?

Đồng thời, bộ quét bảo mật tích hợp (SkillSpector và PII scanner) kiểm tra toàn bộ script và tệp tham chiếu để ngăn chặn:

  • Nguy cơ thực thi lệnh độc hại (command injection, chuỗi lệnh shell không an toàn).
  • Vô tình để lộ token xác thực, private key hoặc thông tin định danh nhạy cảm.
Bash: Chạy kiểm định Tier 1 không cần API Key
# Kiểm tra chất lượng tĩnh và tính điểm cho một thư mục skill
skillevaluator quality-check ./skills/my-skill

# Chạy toàn bộ cổng kiểm soát Tier 1 (chất lượng + bảo mật + PII + lint script)
skillevaluator tier1 ./skills/my-skill --no-llm

# Xuất báo cáo đa định dạng phục vụ kiểm định CI
skillevaluator validate ./skills/my-skill --tiers 1 -r json,markdown,sarif -o ./reports

A major advantage of SkillEvaluator is that Tier 1 validation runs entirely offline without paid API accounts. The quality-check command scores SKILL.md against objective structural criteria:

  • Presence of mandatory sections including ## Prerequisites, ## Limitations, and ## Troubleshooting.
  • Whether the frontmatter description defines clear task boundaries rather than speculative keyword stuffing.
  • Actionable CLI examples with documented flags and expected exit codes.

Integrated security analyzers (SkillSpector and PII detection) simultaneously audit scripts and references against vulnerabilities:

  • Command injection, arbitrary shell chaining, or unsanitized subprocess invocations.
  • Hardcoded bearer tokens, API keys, private certificates, or sensitive personal data.
Bash: Running Keyless Tier 1 Validation
# Evaluate deterministic quality score for a skill directory
skillevaluator quality-check ./skills/my-skill

# Run full Tier 1 gate (quality, security, PII, and script linting) without an LLM
skillevaluator tier1 ./skills/my-skill --no-llm

# Export structured multi-format reports for CI review
skillevaluator validate ./skills/my-skill --tiers 1 -r json,markdown,sarif -o ./reports

4. Tier 2 & Tier 3: Chống trùng lặp và đo lường Skill Lift trong Sandbox4. Tier 2 & 3: Deduplication and Live Sandbox Skill Lift

Khi một kỹ năng vượt qua Tier 1, bước tiếp theo là đảm bảo nó không xung đột với các kỹ năng khác trong kho (Tier 2) và thực sự cải thiện kết quả làm việc của agent (Tier 3):

Trong Tier 3, SkillEvaluator thiết lập thử nghiệm A/B hai nhánh đối chứng:

  • Nhánh Baseline (Without Skill): Agent nhận đề bài trong môi trường cô lập không có skill được cài đặt.
  • Nhánh Thử nghiệm (With Skill): Agent nhận cùng đề bài trong môi trường có skill được nạp vào context.

Công cụ ghi lại toàn bộ trajectory (các bước suy luận, lệnh shell đã chạy, tệp đã sửa) và giao cho bộ chấm điểm độc lập (hoặc bộ kiểm thử tùy biến BYOG). Kết quả tính toán ra Skill Lift:

Nếu Skill Lift dương và có ý nghĩa thống kê, kỹ năng được chứng minh là có giá trị thực tế. Nếu Skill Lift bằng 0 hoặc âm, kỹ năng cần được tinh chỉnh lại trước khi phát hành.

Bash: Kiểm tra trùng lặp và đánh giá thực nghiệm A/B
# Đo độ trùng lặp giữa skill mới và toàn bộ kho lưu trữ
skillevaluator similarity-check ./skills

# Chạy thử nghiệm Tier 3 với agent OpenCode trong Docker sandbox
export SKILL_EVAL_LLM_PROVIDER=nv_build
export NVIDIA_API_KEY="your-api-key"
skillevaluator tier3 evaluate ./skills/my-skill -a opencode --n-attempts 3

# Hoặc chạy thử nghiệm trên máy Mac với cơ chế sandbox Seatbelt (không cần Docker)
skillevaluator tier3 evaluate ./skills/my-skill -a opencode --env-mode local

Once a skill passes Tier 1, subsequent tiers verify catalog harmony (Tier 2) and empirical utility (Tier 3):

In Tier 3, SkillEvaluator executes dual-arm randomized controlled trials:

  • Baseline Arm (Without Skill): The agent attempts the benchmark task without access to the skill.
  • Treatment Arm (With Skill): The agent attempts the identical task with the skill installed in its workspace.

The runner records end-to-end trajectories (reasoning traces, tool calls, and file diffs) and scores outputs via deterministic rubrics or Bring-Your-Own-Grader (BYOG) test suites, computing Skill Lift:

A positive, statistically significant Skill Lift proves real-world capability. A zero or negative Lift signals prompt bloat or guidance interference that requires revision before release.

Bash: Overlap Analysis and Live A/B Benchmarking
# Check semantic similarity across the entire catalog
skillevaluator similarity-check ./skills

# Execute Tier 3 live trials using OpenCode inside a Docker sandbox
export SKILL_EVAL_LLM_PROVIDER=nv_build
export NVIDIA_API_KEY="your-api-key"
skillevaluator tier3 evaluate ./skills/my-skill -a opencode --n-attempts 3

# Run locally on macOS using native Seatbelt isolation without Docker
skillevaluator tier3 evaluate ./skills/my-skill -a opencode --env-mode local

5. Tích hợp CI/CD và cài đặt qua VAS5. CI/CD Gating and Installing via VAS

Kỹ năng skillevaluator được tích hợp sẵn vào Vie Agentic Skill với đầy đủ 9 tập tài liệu tham khảo chi tiết trong thư mục references/, bao gồm bảng tra cứu cờ lệnh, cấu hình provider, định dạng test dataset và cẩm nang xử lý sự cố.

Để cài đặt trực tiếp vào dự án mà không cần clone cả kho VAS, bạn chỉ cần sử dụng tính năng Copy Agent Prompt:

Prompt cài đặt nhanh cho Agent
Read the installation manifest at https://vie-agentic-skills.vercel.app/install-manifests/skillevaluator.json and install its declared files into .agents/skills/skillevaluator/.

Hoặc quản lý thông qua CLI nội bộ của VAS:

CLI: Quản lý kỹ năng bằng ./vas
# Tìm kiếm kỹ năng
./vas search skillevaluator

# Cài đặt chế độ link cho Antigravity / Universal
./vas install skillevaluator --target antigravity --mode link

# Cài đặt chế độ copy độc lập vào dự án Claude Code
./vas install skillevaluator --target claude --mode copy --dest "/path/to/project/.claude/skills"

# Kiểm tra trạng thái cài đặt
./vas status --target claude --dest "/path/to/project/.claude/skills"

The skillevaluator skill is bundled in Vie Agentic Skill alongside all 9 comprehensive reference runbooks in its references/ directory, covering flag tables, provider setups, dataset schemas, and diagnostic recipes.

To install directly into any project workspace without cloning the entire repository, use the Copy Agent Prompt feature:

Agent Installation Prompt
Read the installation manifest at https://vie-agentic-skills.vercel.app/install-manifests/skillevaluator.json and install its declared files into .agents/skills/skillevaluator/.

Or install via the native VAS CLI:

CLI: Managing with ./vas
# Search for the skill
./vas search skillevaluator

# Link install into Antigravity / Universal workspace
./vas install skillevaluator --target antigravity --mode link

# Copy install into Claude Code workspace
./vas install skillevaluator --target claude --mode copy --dest "/path/to/project/.claude/skills"

# Verify installation status
./vas status --target claude --dest "/path/to/project/.claude/skills"
