Agent Skills là gì? Cài skill đầu tiên vào dự án của bạnWhat are agent skills? Install your first project skill

Biên soạn bởi Vie Agentic Skill · Dựa trên runbook trong catalogPrepared by Vie Agentic Skill · Based on catalog runbooks

Một tác vụ cụ thể cần nhiều hơn một câu prompt. Skill gom kiến thức, các bước thực hiện và cách kiểm tra vào một bộ hướng dẫn mà agent có thể đọc khi cần.

Bạn sẽ có gì sau hướng dẫn này?

Bạn biết cách chọn một skill, đưa đủ tệp vào đúng thư mục của agent và yêu cầu agent áp dụng runbook cho tác vụ của mình. Ví dụ xuyên suốt là webapp-testing, dùng để kiểm thử ứng dụng web với Playwright.

Tiếp tục theo ứng dụng với hướng dẫn cài skill cho Codex hoặc Claude Code. Nếu đang gặp lỗi, dùng checklist kiểm tra skill không được nhận diện; để chọn đúng lớp cấu hình, đọc Skills, MCP và AGENTS.md.

Skill gồm những gì?

Tệp chính SKILL.md mô tả khi nào dùng skill, đầu vào cần có, quy trình và tiêu chí kiểm tra. Một skill có thể kèm scripts, tài liệu tham khảo, mẫu và assets; chỉ chép riêng SKILL.md có thể làm thiếu phụ thuộc.

Skill cung cấp hướng dẫn và tệp hỗ trợ. Nó không tự cài runtime, cấp tài khoản dịch vụ hay bảo đảm mọi đầu ra đều chính xác. Agent vẫn cần công cụ và quyền truy cập phù hợp.

Chuẩn bị trước khi cài

  • Mở dự án bạn muốn làm việc trong Codex, Claude Code, Cursor hoặc agent tương ứng.
  • Đọc mục đích, yêu cầu và giấy phép của skill. Với ví dụ kiểm thử web, cần ứng dụng chạy được và môi trường Playwright được cấu hình riêng.
  • Chọn phạm vi dự án cho lần thử đầu. Đường dẫn discovery khác nhau giữa các agent; dùng mapping của VAS thay vì tự đoán.

Cách 1: cài bằng Copy Agent Prompt

  1. Mở runbook webapp-testing trong thư viện và xem yêu cầu.
  2. Chọn đúng agent và xem thư mục đích trong prompt. Mapping Codex của VAS hiện dùng .codex/skills/; tài liệu Codex hiện hướng dẫn .agents/skills/. Với chuẩn mới, dùng đường dẫn và cách cài CLI trong hướng dẫn Codex.
  3. Bấm Copy Agent Prompt khi đã xác nhận đích phù hợp, rồi dán vào chat của agent trong dự án đang mở.
  4. Để agent tải đủ tệp từ manifest, đối chiếu SHA-256 và báo kết quả. Dừng xử lý nếu tệp đã có xung đột hoặc kiểm tra hash không đạt.

Luồng này không cần clone toàn bộ VAS. Không đồng ý chạy scripts hay kết nối dịch vụ chỉ vì đã cài bộ hướng dẫn; xem yêu cầu cụ thể của tác vụ trước.

Cách 2: quản lý bằng CLI

Nếu đã có bản clone VAS, chạy từ thư mục gốc của kho:

Với ví dụ Codex hiện tại, dùng --target workspace và đích .agents/skills/. Đây là lựa chọn thư mục universal, không thay đổi mapping codex có sẵn của VAS.

./vas show webapp-testing
./vas install webapp-testing --target workspace --mode copy --dest "/duong-dan/du-an/.agents/skills"
./vas status --target workspace --dest "/duong-dan/du-an/.agents/skills"

Thay /duong-dan/du-an bằng đường dẫn tuyệt đối tới dự án thật. Dùng cùng --dest và --target cho install, status và uninstall. Chế độ copy tạo bản độc lập; link cần giữ nguyên thư mục nguồn.

Với Claude Code, dùng --target claude và thư mục đích .claude/skills; với Cursor, dùng --target cursor và .cursor/skills trong dự án. Python 3.9+ là yêu cầu của CLI; có thể dùng python3 vas.py thay cho ./vas.

Kiểm tra và bắt đầu dùng

Mở tệp SKILL.md tại đích cài, kiểm tra scripts và references cần thiết có mặt. Nếu ứng dụng yêu cầu, nạp lại danh sách skill. Sau đó gửi tác vụ có phạm vi rõ ràng:

Áp dụng webapp-testing để kiểm tra luồng đăng nhập ở môi trường local.
Trước tiên xác nhận địa chỉ ứng dụng, dữ liệu thử và các công cụ còn thiếu.
Báo kết quả từng bước, kèm bằng chứng cho lỗi phát hiện được.

Phân biệt “đã cài đủ tệp” với “đã chạy kiểm thử thành công”. Nếu chưa có môi trường hoặc quyền truy cập, agent cần báo phần chưa kiểm chứng. Khi muốn gỡ bản cài do CLI quản lý:

./vas uninstall webapp-testing --target workspace --dest "/duong-dan/du-an/.agents/skills"

Lỗi thường gặp

  • Agent không thấy skill: kiểm tra thư mục đích, agent đã chọn và yêu cầu nạp lại của ứng dụng.
  • Thiếu helper: tải lại đủ inventory của skill, giữ nguyên cấu trúc thư mục.
  • Chạy không được: xem prerequisites; cài skill không thay thế việc thiết lập Python, trình duyệt hay tài khoản.

A specific task needs more than a short prompt. A skill packages specialist instructions, a workflow and verification steps so your agent can load the guidance when needed.

What will you have?

You will know how to choose a skill, install its complete file inventory in your agent’s discovery folder and apply its runbook to a task. This guide uses webapp-testing, a Playwright-based web testing toolkit.

Continue with installation for Codex or Claude Code. For a missing skill, use the discovery checklist; to choose a configuration layer, compare Skills, MCP and AGENTS.md.

What does a skill contain?

The main SKILL.md describes when to use the skill, required inputs, steps and verification. Scripts, references, templates and assets may be included. Copying SKILL.md alone can leave dependencies behind.

A skill provides instructions and supporting files. It does not install every runtime, grant service access or guarantee correct output. Your agent still needs the appropriate tools and permissions.

Before installing

  • Open your intended project in Codex, Claude Code, Cursor or the relevant agent.
  • Read the skill’s purpose, prerequisites and license. The web testing example needs a running application and a separately configured Playwright environment.
  • Start with project scope. Agent discovery paths differ; use VAS mappings rather than guessing.

Option 1: Copy Agent Prompt

  1. Open the webapp-testing runbook and review its requirements.
  2. Choose your agent and inspect the prompt destination. VAS currently maps Codex to .codex/skills/; current Codex documentation uses .agents/skills/. For that standard, follow the explicit CLI destination in the Codex guide.
  3. Once the destination is appropriate, select Copy Agent Prompt and paste it into your agent’s chat in the open project.
  4. Have the agent download the full manifest inventory, verify SHA-256 and report the result. Stop if existing files conflict or hashes do not match.

This workflow does not require cloning the entire VAS repository. Review the task’s requirements before running bundled scripts or connecting services.

Option 2: use the CLI

From the root of an existing VAS checkout:

For current Codex discovery, use --target workspace with an explicit .agents/skills/ destination. This selects the universal directory without changing the existing VAS codex mapping.

./vas show webapp-testing
./vas install webapp-testing --target workspace --mode copy --dest "/absolute/path/to/project/.agents/skills"
./vas status --target workspace --dest "/absolute/path/to/project/.agents/skills"

Replace /absolute/path/to/project with your project’s absolute path. Use the same --dest and --target for install, status and uninstall. copy creates independent files; link requires retaining the source folder.

For Claude Code, use --target claude and the project’s .claude/skills destination; for Cursor, use --target cursor and .cursor/skills. The CLI requires Python 3.9+; python3 vas.py can replace ./vas.

Verify and use

Inspect SKILL.md in the destination and check that required scripts and references are present. Reload your agent’s skill list if the application requires it, then give it a specific task:

Use webapp-testing to check the login flow in my local environment.
First confirm the app URL, test data and any missing tools.
Report each step and provide evidence for every issue found.

Distinguish a complete installation from a successful test run. The agent should identify anything it could not verify. To remove a CLI-managed installation:

./vas uninstall webapp-testing --target workspace --dest "/absolute/path/to/project/.agents/skills"

Common issues

  • Skill not discovered: check the selected agent, destination and reload requirements.
  • Missing helper: download the full inventory and preserve its directory structure.
  • Execution fails: check prerequisites; installing a skill does not configure Python, browsers or service accounts.
