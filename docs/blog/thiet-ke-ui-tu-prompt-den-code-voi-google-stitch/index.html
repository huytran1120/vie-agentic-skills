UI/UX & Design-to-CodeUI/UX & Design-to-Code

Thiết kế UI từ Prompt đến Code với bộ skill Google StitchDesign-to-Code UI Workflows with Google Stitch Skills

Biên soạn bởi Vie Agentic Skill · Nguồn Google Labs (Apache-2.0)Prepared by Vie Agentic Skill · Sourced from Google Labs (Apache-2.0)

Khi dùng AI coding agent để dựng giao diện, thách thức lớn nhất không nằm ở việc viết từng thẻ JSX, mà là giữ tính nhất quán về màu sắc, typography, spacing và cấu trúc màn hình xuyên suốt dự án. Bộ 12 kỹ năng mới từ google-labs-code/stitch-skills (giấy phép Apache-2.0) chuẩn hóa toàn bộ vòng đời từ ý tưởng thiết kế trên Google Stitch đến mã nguồn React, React Native và shadcn/ui.

When building user interfaces with AI coding agents, the hardest problem is rarely writing individual JSX tags—it is preserving visual consistency across colors, typography, spacing, and screen layouts. The 12 newly imported skills from google-labs-code/stitch-skills (Apache-2.0) standardize the entire lifecycle from Google Stitch designs to production React, React Native, and shadcn/ui codebases.

1. Kiến trúc 3 nhóm kỹ năng của Google Stitch1. The 3-Layer Architecture of Google Stitch Skills

Bộ kỹ năng được chia thành ba giai đoạn nối tiếp nhau rõ ràng:

  • Thiết kế & Đồng bộ (Stitch Design): generate-design sinh giao diện mới từ prompt; code-to-design và upload-to-stitch đẩy mã nguồn hoặc ảnh chụp ngược lên Stitch; extract-static-html xuất HTML tĩnh sạch để kiểm tra.
  • Quản trị hệ thống thiết kế (Design System & Utilities): extract-design-md và manage-design-system trích xuất và đồng bộ token thiết kế; site-md lập bản đồ cấu trúc trang; taste-design áp dụng các nguyên tắc thẩm mỹ UI hiện đại.
  • Triển khai mã nguồn (Stitch Build): react-components, react-vite-dashboard, shadcn-ui và react-native chuyển đổi bản thiết kế thành component thực tế.

The collection is organized into three sequential workflow stages:

  • Stitch Design: generate-design creates screens from prompts; code-to-design and upload-to-stitch sync existing codebases or screenshots back into Stitch; extract-static-html exports clean static HTML previews.
  • Design System & Utilities: extract-design-md and manage-design-system maintain semantic design tokens; site-md maps multi-page site architecture; taste-design enforces visual craft and hierarchy.
  • Stitch Build: react-components, react-vite-dashboard, shadcn-ui, and react-native compile designs into production components.

2. Chuẩn hóa Design System và trích xuất DESIGN.md2. Standardizing Design Systems and Extracting DESIGN.md

Thay vì để agent tự đoán mã màu hex hay kích thước bo góc, quy trình của Stitch sử dụng tệp DESIGN.md làm nguồn chân lý duy nhất. Khi chạy extract-design-md, agent sẽ rút trích bảng màu, hệ thống font chữ và quy tắc khoảng cách từ dự án Stitch hiện có, sau đó dùng manage-design-system để áp dụng đồng bộ lên toàn bộ các màn hình mới.

Instead of letting agents guess hex codes or border radii, Stitch workflows rely on DESIGN.md as a single source of truth. Running extract-design-md captures color palettes, typography scales, and spacing rules from Stitch projects, while manage-design-system applies those tokens consistently across new screens.

3. Chuyển đổi sang React, Vite Dashboard, shadcn/ui và React Native3. Building for React, Vite Dashboards, shadcn/ui, and React Native

Sau khi chốt thiết kế, bạn chọn đúng kỹ năng đích theo nền tảng của mình: shadcn-ui cho ứng dụng web dùng Tailwind và Radix UI, react-vite-dashboard cho trang quản trị dữ liệu, react-components cho thư viện UI thuần, hoặc react-native cho ứng dụng di động.

Once the design is finalized, select the target build skill matching your stack: shadcn-ui for Tailwind and Radix web apps, react-vite-dashboard for analytics dashboards, react-components for modular component libraries, or react-native for mobile targets.

4. Yêu cầu tiên quyết, giới hạn và cách cài đặt qua VAS4. Prerequisites, Limits, and Installing via VAS

Yêu cầu & giới hạn: Các kỹ năng tương tác trực tiếp với Google Stitch yêu cầu người dùng tự cấu hình Stitch MCP server và tài khoản Google Stitch hợp lệ trong môi trường agent. Việc cài đặt qua VAS chỉ sao chép hoặc liên kết tệp tĩnh và không tự động cài đặt MCP hay thực thi mã nguồn ngoài.

CLI: Cài đặt bộ skill Stitch bằng ./vas
# Cài đặt skill sinh thiết kế và quản lý design system
./vas install generate-design extract-design-md manage-design-system --target workspace --mode link

# Cài đặt skill xuất code đích (ví dụ shadcn-ui)
./vas install shadcn-ui --target claude --mode link

# Kiểm tra trạng thái cài đặt
./vas status --target workspace

Prerequisites & limits: Skills that interact directly with Google Stitch require the user to configure a Stitch MCP server and authenticate their Google Stitch account in the agent runtime. Installing via VAS only links or copies static skill files without installing MCP servers or executing external scripts.

CLI: Installing Stitch Skills with ./vas
# Install design generation and design system skills
./vas install generate-design extract-design-md manage-design-system --target workspace --mode link

# Install target build skill (e.g. shadcn-ui)
./vas install shadcn-ui --target claude --mode link

# Verify installation status
./vas status --target workspace
