# Catalog surface

## Mode

Operate. The short cinematic introduction supports discovery; the working
catalog remains the primary task surface.

## User and task

Vietnamese-first AI-agent users find a skill, inspect the runbook and provenance,
choose an agent and installation destination, then copy a real CLI command.

## Direction

The user pinned https://blender-skills.vercel.app/ as the reference and requested
a reasonable redesign of GitHub Pages. Use its charcoal/orange technical-art
language and actual MIT-licensed Blender render, while preserving Vie Agentic
Skill's broader multi-agent identity. This is inspiration, not a pixel clone.
A randomized visual direction or fabricated Blender capabilities for non-Blender
skills would contradict the request.

## Structure and behavior

Purpose and direct catalog entry; credited Blender render; compact compatibility
line; visible Blender collection; searchable list-first catalog with inline
runbook details and installation; Blender discipline pipeline; other collections;
usage and setup guidance; FAQ and source credits.

Blender has its own exact group filter and shareable namespace identifiers.
Installation settings use native progressive disclosure. Open those settings
when following an installation-destination link. Never share local paths.

## Delivery constraints

Static, dependency-free assets; dark default with a usable light alternative.
The source page works at `/docs/`; the build changes the runbook base and stages
all runbooks and supporting files beneath the GitHub Pages repository prefix.
Keep real loading, retry, empty, disabled, clipboard fallback and keyboard states.
